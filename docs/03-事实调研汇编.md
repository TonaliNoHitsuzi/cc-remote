## 1. cc-connect（chenhg5/cc-connect，Go，15,313★，活跃）

- **飞书接入**：官方 SDK WS 长连接（`platform/feishu/feishu.go`），处理 `im.message.receive_v1` + `card.action.trigger`；同进程多 project 共享 WS
- **审批卡管线（与 agent 无关）**：引擎统一生成卡片（engine.go:11739+），`perm:` 回调 → 匹配 pending → `RespondPermission`；**ACP agent 已实现完整往返**（agent/acp/session.go:486-693）
- **内置 opencode(run) 后端是残废的**：RespondPermission 空实现（#1100）、ask 即拒、每条消息冷启动、无会话续接、无 cwd——**本项目弃用，走 ACP agent**
- **多项目**：`[[projects]]` 每项目独立 work_dir + agent + platforms + admin_from/users ACL；`/dir` 运行时切换
- **队列/去重**：每会话 FIFO（上限 5，engine.go:3184+）；去重窗口默认 60s（core/dedup.go）
- **白名单**：`allow_from`（用户 open_id）+ `allow_chat`（群 chat_id）
- **Web Dashboard**：内置 Beta，:9820，会话列表/聊天/项目 CRUD/`/web setup`
- **入站能力**：`POST /hook`（body `{session_key, prompt|exec}`，外部触发 agent 或 shell）；`[[commands]]` 可 exec 任意 shell；bridge=WS 服务器（9810）可接外部适配器
- **部署**：npm / brew / GitHub Releases（含 Windows amd64+arm64）；**无官方 Docker 镜像**；data_dir 默认 `~/.cc-connect`
- **多机**：同 AppID 跨机 = 飞书随机投递丢消息（#1562 实证）；**多 bot（不同 AppID）可行**（#1563 已修 per-project WS）
- **license**：仓库无 LICENSE 文件，README 自述 MIT——个人用 + 提 issue 催

## 2. opencode（v1.18.26 锁定）

- **`opencode acp`**：Agent Client Protocol over stdio（nd-JSON），`session/request_permission` 双向 RPC——本方案核心
- **`opencode run`**：`--format json` / `-c` 续上轮 / `-s <id>` 续指定 / `--dir`；headless 无权限应答途径（`--auto` 全批，否则自动拒）
- **serve API**：默认 127.0.0.1:4096；`OPENCODE_SERVER_PASSWORD` 开 Basic Auth；`POST /session/:id/permissions/:permissionID`（body `{response, remember?}`）应答权限 + `GET /event` SSE 收 `permission.asked`——**兜底 B 的两块积木**；无 OpenAI 兼容端点
- **权限**：config 三态 allow/ask/deny（最后匹配生效，支持通配与按工具输入匹配）；默认多数工具 allow、`external_directory` ask、`.env` 读拒
- **插件**：JS/TS（Bun），`~/.config/opencode/plugins/`；事件含 `tool.execute.before/after`、`session.idle/created/...`、`permission.asked/replied`；源码级另有 `permission.ask` mutator 钩子（未文档化）；v2 做 ntfy 用 `session.idle` + fetch
- **多 agent profile**：config `agent` 字段 / `agents/*.md`；skills 全局或项目级
- **凭证**：`~/.local/share/opencode/auth.json`（`opencode auth login`），支持 75+ provider / OAuth 订阅
- **Windows**：官方二进制有，但本项目在 WSL2 Linux 容器跑，绕开

## 3. 飞书开放平台

- **免费基础版**支持自建应用 + 机器人全功能；个人免费建团队（一人即可）
- **长连接模式**：仅企业自建应用可用；官方 SDK（`@larksuiteoapi/node-sdk` WSClient 等）自动重连；每应用最多 50 连接；**无需公网 IP/域名/内网穿透**；事件需 3s 内处理完
- **频控**：发消息单用户 5 QPS、接口级 1000 次/分——个人自用碰不到
- **流式**：CardKit 流式更新（打字机，全量传平台算增量，不走 QPS 限制）；卡片操作上限 10 次/秒；**需客户端 ≥7.20**
- **交互卡**：按钮/下拉 → `card.action.trigger` 回调，**长连接模式支持**（3s 内响应）——审批卡的官方依据
- **主动单聊**：机器人可主动发消息给可用范围内用户（scope：im:message 系列）
