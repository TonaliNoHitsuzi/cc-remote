# 配置说明（docker/config.toml）

> 凭证类一律走 `.env`（见 `.env.example`），本文件可安全入库。改完执行 `docker compose restart cc-remote` 生效。

## 全局

| 配置 | 默认 | 说明 |
|---|---|---|
| `data_dir` | `/data` | 会话/队列持久化（compose 已挂载宿主 `docker/data`），勿改 |
| `[log] level` | `info` | 排障改 `debug` |

## 输出行为 `[display]`

| 配置 | 默认 | 说明 |
|---|---|---|
| `mode` | `quiet` | **消息入栈模式**：turn 结束合并为一条发出（实测单任务 1-4 条消息）。`full`=全量实时（消息很多），`compact`=隐藏中间但分段发 |
| `show_context_indicator` | `true` | 回复尾部分行 footer：模型 / 上下文（量+百分比）/ 缓存命中（真实数据，opencode 上报） |
| `show_workdir_indicator` | `false` | footer 不显示工作目录行 |
| `thinking_messages` / `tool_messages` | `false` | 思维链/工具消息（quiet 下强制关） |

## 会话与超时

| 配置 | 默认 | 说明 |
|---|---|---|
| `turn_timeout_mins` | `30` | 单轮硬上限，超时停止并可发消息续跑（会话保留） |
| `reset_on_idle_mins` | `0` | **0=永不空闲分裂**，仅显式 `/new` 开新会话。默认 30（分钟）会自动分裂 |

## 自定义指令 `[[commands]]`

```toml
[[commands]]
name = "gui"
description = "在电脑上打开 opencode 对话界面"
exec = "touch /share/gui.flag"
```

QQ 里发 `/gui` 直接执行 shell（不经过 LLM）。可自行添加更多。

## 平台 `[[projects.platforms.options]]`

| 配置 | 默认 | 说明 |
|---|---|---|
| `app_id` / `app_secret` | `${QQ_APP_ID}` 等 | 环境变量插值，值在 `.env` |
| `sandbox` | `true` | 沙箱模式（申请指南第 4 节）；正式发布后改 `false` |
| `allow_from` | `${QQ_ALLOW_FROM}` | **白名单**（`/whoami` 获取 openid），只放你自己 |
| `markdown_support` | `true` | **按钮渲染必要条件**，勿关 |

## Agent `[projects.agent.options]`

| 配置 | 说明 |
|---|---|
| `work_dir` | agent 工作目录。**必须与宿主 WSL 绝对路径一致**（`/home/<user>/AgentRoot/cc-remote`），否则 opencode 会话域隔离，GUI 无法追踪 QQ 会话 |
| `env.OPENCODE_CONFIG` | 独立 opencode 配置（模型/instructions/skills），与本地 opencode 物理隔离 |

## 输出规范 `docker/qq-style.md`

每轮注入的系统级指令（8 条：静默工作/流程+结论/提问协议/文件回发/skill 路由/围观提示/围观检测/GUI 唤醒）。改完 `docker compose restart` 生效。

## 宿主侧配套（非容器内配置）

| 组件 | 位置 | 说明 |
|---|---|---|
| `ccwatcher.exe` | `C:\Users\<you>\Scripts\` | 托盘看门狗：ToDesk 浮窗自动收起 + 围观状态桥（`/share/watching`）+ GUI 唤醒（`/share/gui.flag`）；源码 `ccwatcher.cs`，csc 编译 |
| 开机自启 | Startup 目录 | ccwatcher 快捷方式 + 计划任务 `WSL-Autostart-cc-remote`（登录拉起 WSL→Docker→容器） |
| 每日重启 | WSL systemd | `cc-remote-restart.timer`（04:00，治 ACP 会话泄漏） |
