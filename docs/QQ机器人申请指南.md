# QQ 机器人申请指南（cc-remote 部署前置）

> 全程约 20-30 分钟（含实名认证）。本指南为 2026-09-02 实战记录，平台界面如有变动以官方为准。

## 1. 注册开发者（个人）

1. 浏览器打开 [q.qq.com](https://q.qq.com)，用你的 QQ 扫码登录
2. 完善开发者信息：选择**个人开发者**，完成实名认证（身份证 + 人脸，一次性）
3. 免费版即可：机器人收发消息、按钮交互、Markdown 消息全可用

## 2. 创建机器人

1. 控制台 → **创建机器人**
2. 填写：名称（如 `cc-remote-bot`）、简介、头像（随意）
3. 创建完成进入开发设置

## 3. 获取凭证

开发设置页复制两个值：

| 项 | 去向 |
|---|---|
| **AppID** | `docker/.env` 的 `QQ_APP_ID` |
| **AppSecret** | `docker/.env` 的 `QQ_APP_SECRET` |

## 4. 沙箱配置（免发布实测）

正式发布需审核；沙箱模式可立即与自己单聊实测：

1. 机器人管理 → **沙箱配置**
2. 把**你自己的 QQ 号**添加为测试成员
3. cc-remote 的 `config.toml` 保持 `sandbox = true`
4. 手机 QQ 搜索机器人名称 → 发送消息即开始对话

## 5. 部署后：白名单收紧

机器人上线后第一件事，给它发：

```
/whoami
```

返回你的 openid，填入 `.env` 的 `QQ_ALLOW_FROM`，重启容器——此后只有你能触发 agent（安全红线）。

## 6. 正式发布（可选）

沙箱够个人使用；如需正式环境（脱离沙箱限制）：

- 机器人管理 → 发布 → 版本管理 → 创建版本并提交审核
- 通过后将 `config.toml` 的 `sandbox` 改为 `false`

## 频控参考（个人够用）

| 场景 | 限制 |
|---|---|
| 被动回复（回你的消息） | 每条消息可回 4 次，60 分钟窗口，5-10 QPS |
| 主动消息 | **1000 条/天/用户**、20 条/分钟 |
| 按钮交互 | 官方 WS 网关回调，长连接免公网 IP |

cc-remote 的 quiet 输出模式下单任务约 1-4 条消息，日常重度使用远够。

## 常见问题

- **搜不到机器人**：确认沙箱配置已加你的 QQ 为测试成员，且 `sandbox = true`
- **按钮不显示**：`config.toml` 里 `markdown_support = true` 是必要条件（纯文本消息携带 keyboard 会被网关忽略）
- **消息发不出**：检查 AppSecret 是否最新（后台可重置）；容器日志看 `gateway READY` 是否出现
