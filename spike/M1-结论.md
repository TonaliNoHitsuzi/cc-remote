## 关键实现细节（给 M2/M4）

- **`markdown_support = true` 是按钮渲染的必要条件**：msg_type=0 纯文本消息携带 keyboard 字段会被 QQ 网关忽略（消息能送达但无按钮）；必须 msg_type=2（markdown）+ keyboard
- 按钮回调：`INTERACTION_CREATE` 事件，`button_data` 格式 `perm:{allow|deny|allow_all}:qqbot:{session_key}`，引擎自动转发为 permission response（perm:deny 拒绝路径与 allow 同构，ACP 层已在 M0 验证拒绝逻辑，M4 一并实测）
- 文字指令兜底可用：直接回复"允许/拒绝/允许所有"同样生效（引擎内建中文匹配，2026-09-02 19:47 实测）——按钮不可用时的降级路径
- 沙箱模式 `sandbox=true` 正常工作；正式发布需在 q.qq.com 操作（非阻塞）
- cc-connect 二进制：main@b39c11f 源码编译（`-tags no_web -buildvcs=false`，Docker golang:1.25 + goproxy.cn），产物 `spike/bin/cc-connect-dev`；v1.5.0 release 不含 #1746 且无 qqbot 按钮验证，M2 继续用源码编译
- `pkill -f cc-connect` 会误杀自身 bash（命令行匹配），用 `pkill -x cc-connect-dev`
