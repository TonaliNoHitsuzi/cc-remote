# 输出优化结论（2026-09-02 拷问定稿 + 实测定稿）

## 最终配置（全部经 spike 实战验证）

| 项 | 配置 | 效果实测 |
|---|---|---|
| 消息入栈 | `[display] mode="quiet"` | 单任务 **1 条**（优化前同任务 ~10 条）；turn 级缓冲，结束合并发出，超 2000 字符代码块感知切割（内置） |
| 思维链过滤 | cc-connect **补丁**（见下） | 独白不再泄漏（补丁前 "Let me..." 直进正文） |
| 上下文感知 | `show_context_indicator=true` | 回复尾部 `[ctx: ~N%]` |
| 防长跑 | `turn_timeout_mins=30` | 超时停止+提示，发消息即 resume 续跑（源码注释实证） |
| 消息计数 | hooks `message.sent` → data/msg-count.log | 观测用，`bash status.sh` 一键查 |
| 提示词注入 | `env OPENCODE_CONFIG=spike/qq-opencode.json` → `instructions:[qq-style.md]` | 每轮系统级生效；本地 opencode 不设此变量，**物理隔离零影响** |

## qq-style.md 终版（3 条）

1. 任务进行中不输出内容；权限请求由系统卡片呈现，无需复述。
2. 任务结束时必须输出两部分，缺一不可：先"本次工作流程"（每步一行，一行一个动作，简短），再"最终结论"（完整清晰）。
3. 需要用户决策时：清晰提出一个问题后立即结束本轮等待回复；不连续追问；不使用任何会等待交互确认的工具。

## cc-connect 补丁（待提 PR 上游）

`agent/acp/mapping.go:235`：opencode 的思维链事件名是 `agent_thought_chunk`，cc-connect 只认 `agent_thinking_chunk`，对不上时落入 "Last resort" 分支被当**正文** EventText 发出（quiet 挡不住）。补丁 = 列表加 `"agent_thought_chunk"` → 正确归类 EventThinking → thinking_messages=false 滤掉。

## 文件路由（2026-09-02 实测定稿）

| 方向 | 机制 | 实测 |
|---|---|---|
| 下行 agent→QQ | agent 执行 `cc-connect send --file/--image/--tts`（CLI 经 api.sock 投递，qqbot 富媒体 API，≤50MiB 默认/20MiB qqbot 侧）；qq-style.md 第 4 条已注入用法 | ✅ 长程任务中 agent 自主发送 notes.md |
| 上行 QQ→agent | C2C attachments 自动下载（图片+文件分类，20MiB）进 prompt | ✅ txt 与图片均正确处理 |
| 平台限制 | 文件消息**不能携带文字**（独立富媒体消息）；图片消息可以带文字；"允许所有"= 会话级自动批准 | 实测确认 |

长程任务综合账本：权限卡 1 + 自动批准确认 1 + 文件 1 + 汇报 1 = **4 条/多步跨盘任务**（优化前估 15-20 条）。CLI 调用需 `CC_DATA_DIR` 指向 spike/data（自定义 data_dir 时）；M2 容器内 cc-connect 进 PATH + 默认 data_dir，指令可简化。

## 轻量化记录（2026-09-02）

- Windows 侧双 PowerShell watcher（~160MB）合并为单 C# exe：`Scripts/ccwatcher.cs` → `ccwatcher.exe`（系统 csc 编译，~24MB，Startup/ccwatcher.lnk 自启）
- 功能不变：ToDesk 浮窗自动收起（实测命中 Left+3/Top+8）+ 围观状态桥（/share/watching 5s 刷新）
- 闲时内存：容器 cc-connect ~39MB + ccwatcher ~24MB ≈ **63MB**；使用时 opencode 会话进程按需 spawn、空闲 30min 自动回收（容器内实测：无会话时仅 cc-connect 一个进程）
